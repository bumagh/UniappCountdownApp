- `user-manager.ts` 中还存在 `userToken` 键，需要后续统一

## 6. 数据流设计

### 6.1 首页数据流

1. 页面 `onShow`
2. 读取 `token`
3. 调用 `incrementLoginDays`
4. 将 `login_days` 写入 storage
5. 调用 `loadData`
6. 拉取用户、分类、倒数日数据
7. 经计算属性分组后渲染

### 6.2 个人中心数据流

1. 页面 `onShow`
2. 拉取用户信息
3. 拉取分类列表
4. 拉取倒数日统计
5. 拉取归档数据
6. 从 storage 读取 `careMode`
7. 从 storage 读取 `loginDays`
8. 渲染个人中心

### 6.3 登录成功数据流

1. 微信登录成功
2. 写入 `token`、`userid` 等缓存
3. 首页收到 success 事件
4. 重新调用 `incrementLoginDays`
5. 刷新倒数日卡片
6. 重新加载业务数据

## 7. 缓存设计

### 7.1 storage 项

- `token`
- `userid`
- `loginDays`
- `careMode`
- `user_avatar`
- `gender`
- `app_version`

### 7.2 缓存策略

- `loginDays`：由首页进入时调用后端更新后写入本地，个人中心只读本地
- `careMode`：本地持久化
- `app_version`：版本检测使用

### 7.3 已识别问题

- `token` 与 `userToken` 命名不统一
- `loginDays` 的最终可信来源需要明确为服务端或本地其一

## 8. 详细功能设计补充

### 8.1 字体大小调节功能设计建议

需求来源：README 中提出“字体大小需要可以调节”。

建议实现：

- 在个人中心新增“字体大小”设置项
- 提供 3~4 档字体倍率，如：标准 / 稍大 / 大字 / 超大
- 使用全局 class 或 CSS 变量控制字号
- 保持与关怀模式兼容

建议缓存键：

- `fontScale`

### 8.2 编辑图标显著性优化建议

需求来源：README 中提出“编辑符号不明显不易识别”。

建议实现：

- 放大编辑按钮尺寸
- 提升对比度与底色
- 补充文字标签，如“编辑”
- 在关怀模式下提高按钮点击热区

### 8.3 120 岁倒数日快捷添加设计建议

建议逻辑：

1. 用户进入首页或个人中心时检测是否已有 `120岁` 相关倒数日
2. 若无，则在适当位置展示快捷卡片或弹窗
3. 用户确认后自动生成对应倒数日

### 8.4 页面转发配置建议

建议为以下页面补充转发信息：

- 首页
- 详情页
- 分享页
- 个人中心活动页（如有）
