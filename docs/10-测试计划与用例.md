# 奇妙日测试计划与用例

## 1. 测试目标

验证奇妙日在 H5 与微信小程序环境下的核心功能、兼容性、可用性与稳定性，确保其满足当前交付与发布要求。

## 2. 测试范围

### 2.1 功能范围

- 登录 / 注册 / 信息补全
- 首页倒数日展示
- 分类管理与分类查看
- 日历页查看
- 个人中心与 `loginDays`
- 编辑 / 详情 / 删除 / 归档 / 置顶
- 分享与版本更新
- 关怀模式与字体调节（规划功能）

### 2.2 平台范围

- H5 浏览器
- 微信内 H5
- 微信小程序

### 2.3 特殊机型关注

- 华为 nova 5 Pro / SEA-AL10 底部布局适配问题

## 3. 测试策略

### 3.1 测试类型

- 功能测试
- 回归测试
- 兼容性测试
- 真机测试
- 冒烟测试

### 3.2 测试方式

- 手工测试为主
- 结合开发日志与接口联调结果验证
- 对高频路径进行多轮回归

## 4. 测试环境

### 4.1 H5 环境

- Chrome
- Edge
- 微信内置浏览器

### 4.2 小程序环境

- 微信开发者工具
- 微信真机环境

### 4.3 接口环境

- 开发环境接口
- 生产/测试环境接口（视发布阶段而定）

## 5. 测试重点

- 登录态识别是否稳定
- `loginDays` 是否正确更新与展示
- 重复事件日期计算是否正确
- 置顶、归档、删除是否正常
- 关怀模式和页面字体是否可读
- 微信分享、转发、订阅消息预留能力是否可工作
- 版本升级后缓存清理和跳转逻辑是否正确

## 7. 缺陷分级建议

- P0：无法登录、无法进入首页、核心数据丢失
- P1：新增/编辑/删除/详情异常，版本更新异常
- P2：样式错位、字体异常、兼容性问题
- P3：文案、细节交互、低频边角问题
