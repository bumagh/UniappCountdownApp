## 2. 项目简介

- **项目名称**：奇妙日
- **项目类型**：UniApp 跨端倒数日应用
- **支持平台**：H5、微信小程序
- **开发模式**：单人兼职开发
- **开发辅助**：AI 辅助开发
- **后端支撑**：BuildAdmin

奇妙日聚焦于“重要日期管理”和“倒数表达”，支持用户记录纪念日、计划节点、重复事件，并通过分类、日历、分享、个人中心等模块形成完整产品闭环。

## 4. 当前技术方案总结

### 4.1 前端技术方案

- UniApp + Vue3 + TypeScript
- Vite 构建
- 页面 + 组件 + 服务层 + 工具层分层组织

### 4.2 后端协作方案

- 使用 BuildAdmin 作为后台与接口支撑
- 前端通过 `apiService.ts` 统一访问接口

### 4.3 跨端适配方案

- 使用 `#ifdef H5` / `#ifdef MP-WEIXIN` 处理平台差异
- H5 侧集成微信 JS-SDK
- 小程序侧适配微信登录与开放能力
