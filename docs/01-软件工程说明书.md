# 奇妙日软件工程说明书

## 1. 项目概述

- **项目名称**：奇妙日
- **项目类型**：基于 UniApp 的跨端倒数日应用
- **支持平台**：H5、微信小程序
- **核心定位**：帮助用户记录、管理和展示重要日期、重复日程与倒数信息

奇妙日是一个以“倒数日 / 纪念日 / 重复提醒”为核心的轻量级应用。项目采用 UniApp + Vue3 + TypeScript 构建，前端通过统一代码同时适配 H5 与微信小程序，并对登录、分享、请求、资源构建等环节做了平台分支处理。

## 5. 核心模块说明

### 5.1 应用启动模块

入口文件：`src/main.ts`、`src/App.vue`

职责：

- 创建 UniApp 应用实例
- 应用启动时检查版本
- 拉取服务端最新版本信息
- 当版本变化时清理本地缓存并跳转登录页
- 获取系统信息，确保页面初始化完成后再渲染

特点：

- `App.vue` 使用 `isReady` 延迟渲染
- 含 H5 端缓存、Cookie、Service Worker 清理逻辑
- 含版本升级后强制重新登录策略

### 5.2 首页模块

文件：`src/pages/index/index.vue`

职责：

- 展示全部倒数日
- 区分置顶、未来、已经三类数据
- 支持列表 / 格子两种布局切换
- 支持关怀模式切换
- 支持微信登录成功后的数据刷新
- 进入页面时更新并缓存 `loginDays`

关键逻辑：

- `onShow()` 中通过 `token` 判断登录态
- 登录后调用 `apiService.incrementLoginDays()`
- 将返回的 `login_days` 缓存到本地 storage
- 加载用户、分类、倒数日数据
- 根据 `repeat_cycle` 和 `repeat_frequency` 计算最近一次未来日期

### 5.3 分类页模块

文件：`src/pages/categories/categories.vue`

职责：

- 分类维度查看倒数日
- 展示奇妙本 / 分类聚合内容
- 作为从首页抽屉跳转的主要聚合页

### 5.4 日历页模块

文件：`src/pages/calendar/calendar.vue`

职责：

- 从日期视角查看倒数日内容
- 形成与首页、分类页互补的浏览模式

### 5.5 个人中心模块

文件：`src/pages/profile/profile.vue`

职责：

- 展示用户头像、昵称、生日
- 展示奇妙日统计信息
- 展示累计登录天数 `loginDays`
- 分类侧边抽屉、归档管理、提醒开关、关怀模式开关、退出登录

关键逻辑：

- `onShow()` 中从 `uni.getStorageSync('loginDays')` 读取累计登录天数
- 加载当前用户、分类、统计数据、归档数据
- 从 storage 同步关怀模式状态

### 5.6 登录与注册模块

目录：`src/subpackages/login`、`src/subpackages/register`

职责：

- 用户账号登录
- 微信登录
- 新用户信息补全
- 注册与密码登录

关键组件：

- `FloatWechatLogin.vue`

平台适配：

- H5 与微信小程序分别处理登录能力
- 小程序端采用头像选择与昵称填写能力实现用户信息收集

### 5.7 倒数日编辑与详情模块

目录：`src/subpackages/edit`、`src/subpackages/detail`

职责：

- 创建 / 编辑倒数日
- 查看倒数日详情
- 归档、置顶、分享等扩展操作

### 5.8 展示组件模块

#### `CountdownCard.vue`

职责：

- 单个倒数日卡片展示
- 支持列表 / 网格布局
- 显示“还有 / 已经 / 就在今天”等状态
- 适配关怀模式

#### `FloatWechatLogin.vue`

职责：

- 未登录时悬浮展示微信登录入口
- 区分 H5 与微信小程序登录方式

### 5.9 埋点与行为分析模块

目录：`src/utils/analytics.ts`

职责：

- 统一记录前端关键行为事件
- 自动补充时间戳、页面路由、平台、用户标识
- 对埋点负载进行裁剪与本地持久化
- 为后续接入服务端日志上报保留统一出口

核心约束：

- 本地缓存 key：`analytics_events`
- 最多保留最近 `200` 条事件
- 事件负载需避免写入超长文本与敏感信息
- 登录、资料补全、倒数日增删改归档、分享、关怀模式、分类点击需覆盖成功与失败分支

## 9. 跨端适配设计

### 9.1 H5 适配点

- `request.ts` 中 H5 请求分支
- `axios.ts` 中当生产环境配置为 `getCurrentDomain` 时自动取当前域名
- `wechatJSSDK` 用于微信内 H5 分享
- `App.vue` 中包含 Cookie / Cache / Service Worker 清理

### 9.2 微信小程序适配点

- `request.ts` 中 MP-WEIXIN 请求分支
- `axios.ts` 中小程序生产环境默认回退到固定线上域名
- `FloatWechatLogin.vue` 中使用微信开放能力收集头像和昵称
- `apiService.loginByWeixin()` 在小程序环境走 `loginByMiniProgram`

### 9.3 通用适配点

- 通过 `#ifdef H5` / `#ifdef MP-WEIXIN` 区分平台逻辑
- 使用 `uni.*` API 统一平台能力
- 页面样式中针对刘海屏、胶囊按钮和关怀模式进行适配

## 11. 本地缓存与状态管理

项目未采用复杂全局状态中心作为核心依赖，而是以 storage + 页面内状态为主。

### 10.1 常用 storage 键

- `token`
- `userid`
- `careMode`
- `loginDays`
- `user_avatar`
- `gender`
- `app_version`

### 10.2 状态特点

- 登录态：以 `token` 为主
- 用户 ID：以 `userid` 为主
- 登录天数：首页调用后端刷新，个人中心从 storage 展示
- 关怀模式：本地 storage 持久化

## 11. 构建与发布设计

### 11.1 Vite 构建

`vite.config.ts` 主要特点：

- 使用 `@dcloudio/vite-plugin-uni`
- 自定义静态资源复制插件
- 构建输出到 `dist/build`
- 图片资源输出到 `static/`
- 禁用默认 `publicDir`
- 根据环境变量注入请求地址

### 11.2 环境变量

#### 开发环境 `.env.development`

- `VITE_AXIOS_BASE_URL='http://localhost:8000'`

#### 生产环境 `.env.production`

- `VITE_AXIOS_BASE_URL='getCurrentDomain'`
- H5 根据当前域名拼接 API 根地址
- 微信小程序回退到固定线上域名 `https://app.tutlab.tech`
