# 奇妙日部署文档

## 1. 文档目标

本文档用于说明奇妙日前端项目在本地开发、H5 部署、微信小程序发布时的构建与上线方式，并给出环境变量、构建命令、发布注意事项和运维建议。

## 2. 项目部署范围

当前仓库为 **UniApp 前端项目**，支持：

- H5 部署
- 微信小程序构建与发布

后端服务不在本仓库中，但前端依赖后端 API 提供：

- 用户登录与资料接口
- 分类接口
- 倒数日接口
- 版本管理接口
- 微信 JS-SDK 配置接口

## 3. 环境要求

### 3.1 开发环境

- Node.js 18.20.4
- npm
- HBuilderX 或支持 UniApp 的 IDE
- 微信开发者工具（用于小程序调试）

### 3.2 关键依赖

由 `package.json` 可知，核心依赖包括：

- `@dcloudio/uni-app`
- `@dcloudio/vite-plugin-uni`
- `vue`
- `typescript`
- `sass`
- `weixin-js-sdk`

## 4. 环境变量说明

### 4.1 开发环境 `.env.development`

```env
ENV='development'
VITE_BASE_PATH='./'
VITE_AXIOS_BASE_URL='http://localhost:8000'
```

说明：

- 本地开发默认请求 `http://localhost:8000`
- 适用于本地联调

### 4.2 生产环境 `.env.production`

```env
ENV='production'
VITE_BASE_PATH='/'
VITE_OUT_DIR='dist'
VITE_AXIOS_BASE_URL='getCurrentDomain'
```

说明：

- H5 端若配置为 `getCurrentDomain`，将通过 `window.location` 自动推导域名
- 小程序端若为 `getCurrentDomain`，会在 `src/utils/axios.ts` 中回退到 `https://app.tutlab.tech`

## 5. 本地开发

### 5.1 安装依赖

```bash
npm install
```

### 5.2 启动开发环境

```bash
npm run dev
```

> 当前 `package.json` 中 `dev` 脚本包含 `nvm use 18.20.4 && vite dev`。在 Windows PowerShell / CMD 中若未安装 `nvm` 或脚本不可用，可手工切换 Node 版本后再执行 `vite dev`。

### 5.3 本地联调建议

- 后端接口地址设置为本地服务地址
- 若调试 H5 微信能力，需要确保运行域名可被微信 JS-SDK 正常签名
- 若调试微信小程序，需要在微信开发者工具中配置合法服务器域名

## 6. H5 构建与部署

### 6.1 构建命令

```bash
npm run build
```

构建产物默认输出到：

```text
dist/build
```

### 6.2 构建配置说明

`vite.config.ts` 中的关键处理：

- 输出目录：`dist/build`
- 静态图片输出到 `static/`
- 默认 `publicDir` 被禁用
- 通过自定义插件复制 `src/static` 下的 tabbar 资源

### 6.3 H5 部署方式

推荐部署到 Nginx、Apache 或任意静态资源服务器。

### 6.4 Nginx 参考配置

```nginx
server {
    listen 80;
    server_name your-domain.com;

    root /var/www/qimiaori/dist/build/h5;
    index index.html;

    location / {
        try_files $uri $uri/ /index.html;
    }
}
```

> 注意：实际输出目录可能需结合 UniApp H5 产物结构确认。若使用 HBuilderX 或其他构建方式，目录可能与纯 Vite 输出略有差异。

### 6.5 H5 上线检查项

- 域名已备案（如中国大陆正式环境需要）
- HTTPS 已启用
- 微信分享签名域名已加入白名单
- 后端接口允许当前域名访问
- 静态资源路径正常

## 7. 微信小程序部署

### 7.1 小程序基础配置

从 `src/manifest.json` 可知项目已配置微信小程序能力，当前使用的 `appid` 为项目已有配置值。

### 7.2 构建流程

建议使用 HBuilderX 或 UniApp 官方方式构建微信小程序版本：

1. 打开项目
2. 选择发行到微信小程序
3. 生成小程序代码
4. 在微信开发者工具中导入生成目录
5. 配置合法域名、上传、提审、发布

### 7.3 小程序上线前检查项

- 服务器域名加入 request 合法域名
- 若使用文件/图片上传，也需配置 upload/download 合法域名
- 登录、头像、昵称能力符合微信平台规范
- 小程序基础库版本满足当前组件能力要求
- 接口证书、HTTPS、域名备案齐备

### 7.4 当前已识别的小程序适配点

- `apiService.loginByWeixin()` 在 MP-WEIXIN 环境走 `loginByMiniProgram`
- `FloatWechatLogin.vue` 使用小程序开放能力收集头像昵称
- `request.ts` 对 MP-WEIXIN 环境做了独立网络请求分支

## 8. 发布流程建议

### 8.1 H5 发布流程

- 开发自测
- 测试环境验证
- 构建生产包
- 上传静态产物
- 配置 Nginx
- 冒烟测试
- 正式切流

### 8.2 微信小程序发布流程

- 本地开发调试
- 微信开发者工具联调
- 真机验证
- 上传体验版
- 产品/测试验收
- 提交微信审核
- 审核通过后发布

## 9. 运维与版本策略

项目在 `App.vue` 中内置版本检查逻辑：

- 启动时调用 `apiService.getLatestVersion()`
- 若本地版本与服务端不一致，清空缓存并要求重新登录

建议后端版本表至少维护以下字段：

- `version`
- `title`
- `description`
- `update_method`
- `update_rule`

## 10. 安全建议

- 所有正式环境接口必须使用 HTTPS
- 统一 token 键名，避免 `token` / `userToken` 混用
- 不要在前端硬编码敏感密钥
- 微信相关密钥只应在服务端保管
- 版本升级清理缓存时应避免误删业务上必须保留的用户离线数据

## 11. 部署检查清单

### 11.1 通用检查

- Node 版本正确
- 环境变量正确
- 后端 API 可用
- 登录流程可用
- 倒数日 CRUD 可用
- 分类 CRUD 可用
- 版本检查可用

### 11.2 H5 检查

- 首页可打开
- 刷新不 404
- 微信内分享可用
- 静态图片可加载

### 11.3 微信小程序检查

- 登录流程正常
- 页面跳转正常
- 分类/详情/编辑页正常
- 网络请求域名配置正确
- 真机环境 UI 正常
