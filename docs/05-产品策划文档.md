# 奇妙日产品策划文档

## 1. 产品概述

### 1.1 产品名称

奇妙日

### 1.2 产品定位

一款面向个人用户的跨端倒数日与纪念日管理工具，帮助用户记录重要事件、查看未来安排、回顾已发生的重要时刻，并通过分类、日历、分享等能力提升使用体验。

### 1.3 产品形态

- H5 应用
- 微信小程序

### 1.4 产品愿景

让用户以轻量、直观、富有情感表达的方式管理人生中的重要日期，并在不同平台中获得一致体验。

## 2. 目标用户

### 2.1 核心用户

- 需要记录纪念日、生日、考试、计划节点的人群
- 有长期健康、生活、学习计划的人群
- 喜欢倒数日、时间管理和轻仪式感产品的用户

### 2.2 潜在用户

- 恋爱/家庭用户
- 学生用户
- 健康管理用户
- 自我成长用户
- 中老年用户（关怀模式）

## 3. 用户痛点

- 重要日期分散在聊天记录、日历、备忘录中，难以统一管理
- 普通提醒应用缺少情感化表达与倒数视图
- 重复类事件（如用药、复诊、纪念活动）不方便持续追踪
- H5 与小程序体验不统一，登录方式复杂
- 老年或弱视用户对字体、对比度和阅读性有更高要求

## 4. 产品目标

### 4.1 业务目标

- 建立倒数日管理核心功能闭环
- 提供 H5 与微信小程序双端覆盖
- 提高用户留存与长期使用频率
- 通过登录天数、关怀模式、分享能力增强长期价值

### 4.2 用户目标

- 快速创建并管理重要日期
- 一眼看清未来和已发生事件
- 能按分类与日历浏览事件
- 能在不同终端随时访问

## 7. 核心使用场景

### 场景 1：记录重要纪念日

用户希望记录生日、结婚纪念日、考试日等，并在首页看到“还有多少天”。

### 场景 2：持续跟踪重复事件

用户需要记录复诊、服药、健身、复盘等重复事件，并自动计算下一次日期。

### 场景 3：分类化管理人生事项

用户通过“健康 / 计划 / 纪念”等分类，将不同事项分组管理。

### 场景 4：老年用户使用

用户开启关怀模式后，字体更大、对比更强、点击区域更友好。

### 场景 5：微信生态使用

用户在微信中打开 H5，或在小程序中登录后使用，并进行分享传播。

## 8. 页面规划

### 8.1 首页

目标：作为核心使用入口，展示倒数日主列表。

主要模块：

- 顶部导航栏
- 布局切换
- 关怀模式切换
- 新增按钮
- 置顶区
- 未来区
- 已经区
- 微信登录悬浮入口
- 分类抽屉

### 8.2 分类页

目标：按分类查看倒数日。

### 8.3 日历页

目标：按日期查看事件分布。

### 8.4 个人中心

目标：管理用户资料、统计信息与个性化设置。

### 8.5 登录/注册页

目标：完成身份验证和信息补全。

埋点关注：

- 微信登录点击、发起、成功、失败
- 密码登录发起、成功、失败
- 游客先看看行为
- 首次资料补全页面浏览、提交成功、提交失败

### 8.6 编辑页/详情页

目标：完成倒数日的增删改查闭环。

埋点关注：

- 倒数日创建、修改、删除、归档、恢复归档
- 分类选择使用情况
- 分享面板打开与分享成功
- 关怀模式切换与分类抽屉点击

## 9. 指标建议

### 9.1 核心指标

- DAU / WAU / MAU
- 新增用户数
- 登录转化率
- 首次创建倒数日转化率
- 用户平均倒数日数量
- 次日 / 7日 / 30日留存率

### 9.2 功能指标

- 微信登录成功率
- 新增倒数日成功率
- 分享触发率
- 关怀模式开启率
- 分类使用率
- 归档使用率

### 9.3 埋点事件建议

- 登录转化：`wechat_login_click`、`wechat_login_success`、`password_login_success`
- 登录失败诊断：`wechat_login_failed`、`password_login_failed`
- 首次激活：`profile_completion_page_view`、`profile_completion_success`
- 内容创建转化：`countdown_create_success`、`countdown_create_failed`
- 内容编辑活跃：`countdown_update_success`
- 内容治理：`countdown_archive_success`、`countdown_unarchive_success`、`countdown_delete_success`
- 分享传播：`share_countdown_click`、`share_countdown_success`
- 适老化使用：`care_mode_toggle`
- 分类偏好：`category_click`、`countdown_category_selected`

## 10. 竞品与差异化思路

### 10.1 竞品类型

- 系统计时/提醒应用
- 纪念日类 App
- 习惯打卡类工具
- 日历类应用

### 10.2 差异化方向

- 跨端一致体验
- 更强的重复事件支持
- 更轻的倒数日表达方式
- 情感化文案与卡片设计
- 面向长寿/健康管理场景延展
- 关怀模式支持中老年用户

## 11. 后续产品迭代建议

### 11.1 短期迭代

- 优化首页性能与空状态引导
- 完善登录与注册路径
- 提升微信分享落地页体验
- 统一登录天数逻辑

### 11.2 中期迭代

- 增加提醒订阅能力
- 增加模板中心
- 增加批量管理能力

### 11.3 长期迭代

- 成长体系 / 成就系统
- 社交化分享
- 家庭共管 / 亲友协同
- 会员与增值服务

## 12. 当前版本策划结论

奇妙日当前已具备一个完整可用的 MVP+ 版本雏形，既覆盖了倒数日产品的核心路径，也兼顾了微信生态和 H5 双端场景。下一阶段重点应放在：

- 统一技术规范
- 夯实登录与数据一致性
- 提升稳定性与部署标准化
- 在产品层逐步补充增长与留存机制

当前版本已补充前端统一埋点能力，可用于验证登录转化、首次创建、分享传播、关怀模式与分类使用等核心假设。
